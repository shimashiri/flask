# URL Shortener 🔗

A simple URL shortener built with **Flask** and **SQLite**.  
Enter a long link, and the app will generate a short version that redirects to the original.

## Features
- Generate short URLs automatically
- Store original + short links in SQLite
- Redirect short links to the original site
- Minimal and lightweight Flask app
